# 无功能按钮实现 Spec

## Why
项目中有 ~28 个按钮缺少 onClick 处理逻辑，用户点击后无响应，影响产品体验。

## What Changes
- 为所有无 onClick 的按钮添加功能实现
- 分为三类：需要后端交互的（先做模拟/toast 提示）、可直接实现的（路由跳转/状态切换）、需要弹窗/模态框的

## Impact
- Affected code: 19 个 TSX 文件，~28 个按钮
- No breaking changes

## 实现策略
### 移动端按钮（11个）
- 退出登录：调用 auth API + 清除 cookie + 跳转登录页
- 刷新类：触发数据重新加载 + toast 提示
- 发送/生成类：调用对应 API 或展示 AI 处理中状态
- 绑定店铺：跳转店铺授权流程

### Dashboard 按钮（13个）
- 导出类：生成模拟 CSV 下载或 toast 提示功能开发中
- 详情/优化：打开详情弹窗或跳转详情
- 一键合规检测：触发 AI 任务 + 展示进度
- 计划升级：toast 提示联系管理员

### 共享组件（1个）
- TopBar 通知铃铛：打开通知下拉面板
